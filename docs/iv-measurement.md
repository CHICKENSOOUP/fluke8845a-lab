# IV 测量页面

在仓库目录运行 `python -m fluke8845a.webapp`，然后打开 `http://127.0.0.1:8765/iv.html`。页面使用本机 Python 服务连接仪器；也可以选择模拟器。模拟读数不代表真实测量。

展开“通信与测量参数”选择连接方式和量程。输入并确认外部电压，设置 NPLC 和采样间隔，连接后开始测量。每次改变外部电压后，输入并确认新电压；电流时间曲线和窗口统计从新电压的记录边界重新开始。窗口默认为 60 秒，认为电流稳定时点击“记录 IV 点”。

左侧纵轴可自动设置或手动输入范围；Ctrl 加滚轮缩放纵轴，双击恢复自动范围。电流显示在 µA 和 mA 之间自动切换，窗口内电流绝对值达到 0.5 mA 时使用 mA。数据以 A 保存。

IV 点可以编辑、删除，曲线可以切换线性或带符号对数。保存 JSON 可重新打开完整测量；导出 CSV 分别生成 IV 点和原始电流记录。采集时后台也持续记录原始 CSV。

本页面按用户指定使用 OutG SW 默认值 `2.10.882.24`，该值不是仪器读取或自动核验结果。真实仪器行为未在本轮验证。
