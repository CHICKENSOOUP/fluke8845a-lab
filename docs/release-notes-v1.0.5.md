# v1.0.5 — 版本发布刷新

[简体中文](#简体中文) | [English](#english)

## 简体中文

本版本将当前 `main` 源码状态作为新的正式版本发布，方便从版本号明确的 Release 和 Packages 获取同一份源码。

- 版本号更新为 1.0.5。
- 本次没有新增功能或改变测量行为。
- 发布内容为源码 ZIP 和 SHA-256 校验文件；不包含预编译 Windows EXE。
- 自动化测试和 Mock 启动不代表真实 Fluke 8845A 硬件验证。

## English

This release republishes the current `main` source state under a new stable version so the same source can be obtained from a clearly versioned Release and Packages entry.

- Version updated to 1.0.5.
- No feature or measurement-behavior changes are included.
- Assets are the source ZIP and SHA-256 checksum; no prebuilt Windows executable is included.
- Automated tests and Mock startup do not constitute validation on a real Fluke 8845A.
