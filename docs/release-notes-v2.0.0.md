# Fluke 8845A Lab v2.0.0

## 桌面测量界面

主界面重新围绕实时测量组织。启动后选择串口并连接仪表，连接成功回到测量界面；需要修改积分时间、交流带宽、滤波或目标采样间隔时，再打开“测量参数”。

- 六个模式按钮直接切换直流电压、交流电压、直流电流、交流电流、两线电阻和四线电阻。
- 开始连续采集、单次测量、暂停、停止、量程、平均点数、重新测量和保存曲线集中在同一行。
- 量程选择包含自动量程和各模式支持的固定量程；测量参数与采样间隔在本次采集和保存收尾期间保持锁定。
- 重新测量会先结束并保存正在进行的实验，再清空图表；已保存的实验数据继续保留。
- 接线确认使用简短弹窗；切换测量模式直接执行。开始真实采集或调整电流量程时，弹窗显示本次模式和量程。
- 移除图表中的鼠标十字虚线和单击选点标记；曲线区域保持清晰。

## 曲线与坐标

- 原始读数与滑动平均同时绘制。平均点数可在采集中修改，例如 20 点或 50 点；起始点不足设定数量时按已有有效点计算。
- `Full（全部）` 从 0 显示到最新数据；`滚动跟随` 保持手动设定的时间窗口宽度，随最新数据移动。两种横轴模式互斥。
- `纵轴自动` 按当前可见时间范围中的数据调整纵轴；也可以关闭后手动缩放。
- 普通滚轮缩放横纵轴，Shift + 滚轮缩放时间轴，Ctrl + 滚轮缩放纵轴。手动调整时间范围时，滚动跟随保持开启。
- 滚轮缩放幅度更平滑；曲线重绘和纵轴范围计算加入节流，减少拖动时的重复计算。
- 纵轴单位按数值自动切换，时间轴按显示跨度使用秒、分钟或小时。数据仍按原始 SI 单位和秒记录。

## 保存与导出

实验采集继续逐点写入独立目录，包含原始测量 CSV、实验配置、事件和运行日志。

点击“保存曲线”后选择 CSV 文件名，程序在后台生成两份文件：

1. **简洁曲线 CSV**：本地时间、经过时间、原始值、滑动平均值、单位，共 5 列。
2. **详细曲线 CSV**：文件名带 `_detailed`，保留完整原始测量字段，并增加平均值与平均点数。

两份文件来自同一份完整记录快照。导出使用点击保存时选定的平均点数；异常记录或样本中断后重新开始平均。采集进行中也可导出当时已经完整写入的数据。原始实验文件和已有导出文件不会被覆盖。

## 仪器与版本记录

- Windows 串口连接继续支持端口选择、波特率、数据位、校验、停止位和流控制设置。
- 程序识别 Fluke 8845A，并区分真实仪器和 Mock 数据。各模式的量程与测量设置沿用项目中的官方手册依据。
- 仪表软件版本的面板核对记录按仪表序列号保存在本机；主界面右下角不再显示 OutG SW 和 InG SW。
- 异常读数不会被替换为有效测量值；原始响应与状态保留在实验记录中。

## 使用方式

下载并解压源码包，双击 `run_windows.bat` 启动 Windows 桌面版。在连接窗口选择实际串口及仪表对应的串口参数；没有仪器时可选择 Mock 模式体验界面和采集流程。

本版通过的本机验证以发布记录和自动化结果为准；本次界面改动未进行真实仪器验证。Release 提供源码 ZIP 与 SHA-256 文件。
