# Fluke 8845A Lab v2.1.0

## 桌面与网页界面

- localhost 网页采用与桌面版一致的测量工作区：六个按钮切换直流电压、交流电压、直流电流、交流电流、两线电阻和四线电阻。
- 主界面集中显示实时读数、连接状态、量程、采集控制和曲线；连接及测量参数在各自的设置窗口中调整。
- 切换测量模式直接执行；开始真实采集或调整需要核对接线的设置时，使用简短确认窗口。
- 桌面与网页移除模拟仪器连接入口；自动化测试继续使用内部模拟设备。

## 曲线操作

- 原始读数和滑动平均同时显示。平均点数可在采集中修改，异常或缺失样本会中断平均并重新开始计算。
- 网页的完整平均曲线从原始实验记录计算，近期数据随采集更新；长实验的历史计算按数据规模和耗时降低刷新频率。
- `完整显示` 从时间零点显示到最新数据；`滚动显示` 保持选定的时间窗口并跟随新数据。纵轴自动缩放同时考虑当前窗口内的原始值和平均值。
- 普通滚轮缩放两轴，Shift + 滚轮缩放时间轴，Ctrl + 滚轮缩放纵轴。网页移除曲线中的鼠标十字虚线和选点标记。
- “重新测量”用于开始新的曲线显示，已有实验数据继续保留。

## 保存与导出

- 仪器读数继续逐点写入实验目录中的原始 CSV，采集期间即可保存已完整写入的数据快照。
- 桌面“保存曲线”生成简洁 CSV 和详细 CSV；网页版下载 ZIP，其中包含 `curve.csv` 与 `curve_detailed.csv`。
- 简洁 CSV 包含本地时间、经过时间、原始值、滑动平均值与单位；详细 CSV 保留原始测量字段、平均值和平均点数。
- 网页的历史曲线或清空视图不会导出其他实验的数据；原始实验文件不因曲线显示或导出而改变。

## Windows、连接与启动

- 改善 Windows 短暂占用实验配置文件时的保存处理，重试期间继续检查文件身份并保留原子替换。
- 从源码目录双击 `run_windows.bat` 启动桌面版，双击 `run_web.bat` 启动 localhost 网页版。首次启动按提示准备 Python 环境。
- 连接前在仪表和软件中核对串口参数；桌面版与网页版不能同时占用同一 COM 端口。
- 发布流程使用 UTF-8 和无界面测试配置，并保存测试日志以便检查。

本版自动化测试使用内部模拟器；真实硬件验证结果以实际验收记录为准。
