# Fluke 8845A Lab v2.1.1

## Windows 配置文件保存修复

修复 Windows Server 2022 上实验刚启动就无法保存 `config.json` 的问题。原目录保护句柄申请了删除权限，会让同一实验目录中的临时配置文件无法原子重命名；Windows 返回 `WinError 32`，导致 Python 3.11 发布测试失败，部分 GUI 测试也无法完成实验启动。

目录保护改用读取目录与属性权限，继续禁止采集中的实验目录被重命名或替换。配置文件仍先完整写入临时文件并同步到磁盘，再原子替换；数据文件、路径身份和 junction 检查继续执行。

新增 Windows 实际文件操作测试，覆盖新建及替换配置、采集期间阻止目录改名、关闭记录器后释放目录，以及既有目录替换攻击检查。GitHub 诊断保留了修改前后的重命名对照和文件句柄记录。

## 采集验证计时修复

GUI 探测现在等待记录器建立完成、界面收到实验启动状态后，再开始计算请求的采集持续时间。慢磁盘上的文件初始化耗时不会再挤占采样时间。启动等待、采集与保存收尾仍受总墙钟上限约束。

回归测试加入 3.1 秒的记录器启动延迟，检查开始后能够取得连续有效读数、显示实测间隔并保存数据。

## 2.1 测量界面

本版包含 2.1 的桌面和 localhost 网页界面：六种测量模式、量程与采集控制、原始读数与滑动平均、完整显示和滚动显示，以及简洁与详细 CSV 导出。两个界面均移除了模拟连接入口；内部模拟器用于自动化验证。

源码包通过 `run_windows.bat` 启动桌面界面，通过 `run_web.bat` 启动本机网页界面。Release 提供源码 ZIP 和 SHA-256 校验文件，Packages 提供同版本源码包。

本次验证使用内部模拟设备和真实 Windows 文件操作，未连接真实仪器。
