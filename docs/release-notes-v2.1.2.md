# Fluke 8845A Lab v2.1.2

## Windows 实验配置保存

修复 Windows Server 2022 上启动实验时 `config.json` 原子替换失败的问题。目录保护句柄原先申请了删除权限，阻碍同目录临时文件重命名，系统返回 `WinError 32`。目录保护改用读取目录和属性权限，配置文件可以正常完成写入、同步到磁盘和原子替换。

采集期间仍锁定实验目录的身份并阻止目录改名；记录器关闭后释放句柄。新增真实 Windows 文件操作测试，同时检查新建配置、替换已有配置、目录改名保护和句柄释放。目录替换攻击测试继续检查外部文件原始字节未被改写。

## GUI 采集探测

采集探测等待记录器建立完成、界面收到启动状态后，再计算请求的采集时长。文件初始化耗时不再挤占采样时间，启动、采集和保存收尾仍受原总时限约束。

增加记录器延迟 3.1 秒的回归用例，检查连续读数、实测间隔和数据保存。测试使用内存中的串口替身。

## Python 3.11 测试可靠性

修复高负载 Windows 运行器上的两处测试超时。GUI 行为测试原先将包含 Qt 冷启动的总预算压缩到 3 秒或 8 秒，可能在执行目标断言前先超时；现在统一为 20 秒。采集时长及恢复量程的确认检查保持原有断言，生产仪器的时长限制保持原值。

目录安全测试改用 CPython 的原生 Windows junction 创建函数，直接建立真实 reparse point，并核对属性及目标路径。测试创建目录时无需启动 PowerShell，创建失败直接使测试失败。

Windows 诊断流程先运行完整测试，再采集专项文件句柄证据，使完整测试覆盖冷启动场景。发布流程继续分别执行 Python 3.11 和 3.12 的完整分组测试，以及 Web 前端测试。

## 桌面与网页界面

本版包含 2.1 的统一测量界面：六种模式、量程和自动量程、采集控制、原始读数与可调点数的滑动平均、完整显示和滚动显示，以及独立纵轴自动缩放。

“保存曲线”导出原始点和滑动平均点；简洁 CSV 便于直接分析，实验目录继续逐点保留完整原始记录。桌面和网页移除了模拟连接入口，内部模拟器用于自动化验证。

## 下载与启动

Release 提供源码 ZIP 和 SHA-256 校验文件，GitHub Packages 提供同版本 OCI 源码包。解压源码包后，运行 `run_windows.bat` 打开桌面界面，运行 `run_web.bat` 打开 localhost 网页界面。发布前检查解压后首次启动及网页健康接口。

本轮验证使用软件模拟设备和真实 Windows 文件操作，未连接仪器。
