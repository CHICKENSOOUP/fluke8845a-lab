# Fluke 8845A Lab v2.1.3

## 模式切换动效

桌面版的选中框沿六个测量模式按钮移动，完整包住当前模式，并在切换过程中短暂扩展后收回。网页端同步使用整块高亮面板滑动和扩张效果。键盘焦点有清晰边框；系统启用减少动态效果时，动画会关闭。

## 实时视图

网页标题栏移除了“精密测量”副标题。波形区域使用“实时数据”标题，实时数据来源标签在实时视图中隐藏，历史 CSV 的文件名仍会显示。网页标签页使用 8845A 图标。

## Windows 启动入口

源码 ZIP 不再提供 BAT 启动入口。解压后运行 `Install-Fluke8845A-Shortcuts.vbs`，桌面会创建“Fluke 8845A”和“Fluke 8845A Web”两个带应用图标的快捷方式，并启动桌面版。快捷方式通过 Windows 脚本宿主和 `pyw.exe` 启动，不弹出 CMD 窗口。

首次启动会在项目目录准备 Python 3.11 或 3.12 的专用虚拟环境并安装对应锁定依赖；后续启动复用该环境。Web 快捷方式启动 localhost 服务并打开浏览器。启动失败时会显示日志位置，详细记录保存在 `%LOCALAPPDATA%\Fluke8845A\logs\launcher.log`。已验证的便携构建启动入口也改用隐藏窗口的 VBS 启动器。

## 验证

本版运行了桌面 GUI、Web 前端、Windows 源码启动器和发布包自动化测试；Python 3.11 Windows 全量工作流通过。本次自动化使用软件模拟或隔离的启动替身，没有连接真实 Fluke 8845A。
