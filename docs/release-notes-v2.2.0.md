# Fluke 8845A Lab v2.2.0

本版集中改进 Windows 源码启动、发布文件核验和测试工具，方便继续使用和维护桌面版与本机网页界面。

## Windows 快捷方式启动

桌面版和 Web 版快捷方式会优先检查项目已有的 Python 虚拟环境。环境可用时直接通过其中的 `pythonw.exe` 启动，即使系统没有 Python 启动器也能使用现有环境；环境缺失或不可用时，启动器继续尝试系统 Python 启动器。

启动仍使用隐藏窗口的方式，失败时会给出启动日志位置。首次准备环境仍需满足项目的 Python 和依赖要求。

## 发布文件核验

GitHub Release 的源码 ZIP 和校验文件现在除了核对名称、大小，还会核对 SHA-256 摘要，发现文件内容不一致时报告错误。GitHub Packages 的文件摘要核验也使用相同的流式计算方式。

## 测试工具

本地并行测试产生的日志与临时文件集中保存在项目的 `build/test-artifacts/pytest-shards/` 下，便于查找和管理。测试输出分别记录每个分片完成时的耗时，较快分片不会再计入等待其他分片的时间。

自动化测试增加了 Windows 快捷方式使用已有环境、回退到系统启动器、发布文件摘要异常及测试分片耗时的覆盖。

## 验证范围

本地完整测试结果为 1524 项通过、7 项跳过。Windows 启动器通过脚本测试验证；本轮没有连接真实仪器。源码 ZIP 提供 Windows 启动入口和可复现的构建流程。
