## 实际写入命令

连接：串口打开后先写 `SYST:REM`，再查询 `*IDN?` 并核验 8845A 身份，随后读取仪器错误队列；若身份识别失败，软件会尽力写 `SYST:LOC` 后关闭串口。该先 REM 后收发的顺序遵循编程手册 PDF 第76页（印刷第66页）。仪器设置区允许在停止采集时切换 `SYST:LOC`（Local面板操作）与 `SYST:REM`（Computer远程操作）；切回Computer后重新回读当前模式及参数。即使软件缓存已显示Computer，用户再次请求Computer也会重发 `SYST:REM` 并重新核对仪表状态。真实连接成功后，桌面 Worker 每10秒在停止或暂停状态下查询 `*IDN?` 检查连接和8845A身份；连续采集运行时不插入探测查询，LOCAL 与 MOCK 状态不探测。探测超时、身份变化或串口错误会关闭连接并更新状态；暂停中的实验会以失败状态结束并保存。正常断开写 `SYST:LOC`。仪表RS-232菜单的COMPUTER协议设置与软件的Local/Computer控制权分开：前者须在仪表面板设置，后者使用这两个SCPI命令。

功能配置用 `CONF:VOLT:DC`、`CONF:VOLT:AC`、`CONF:CURR:DC`、`CONF:CURR:AC`、`CONF:RES`、`CONF:FRES`。设置自动量程用 `SENS:<function>:RANG:AUTO ON`；固定量程用 `...:RANG:AUTO OFF` 后写 `...:RANG <SI>`。仅DCV/DCI/RES/FRES写 `...:NPLC`；ACV/ACI写 `SENS:DET:BAND <3|20|200>`。DCV 显式写 `INP:IMP:AUTO ON|OFF` 并查询回读；该模式依据手册在所有量程默认关闭为10 MΩ，启用后仅100 mV、1 V、10 V量程高于10 GΩ。8845A 数字滤波仅适用于 DCV、DCI、2W 和 4W；软件只允许在 NPLC 10 或 100 启用（慢于 1 PLC）。`CONF` 将数字滤波预设为 ON，因此配置时软件在 `CONF` 后先发送 `SENS:<function>:FILT:DIG OFF`，检查错误队列并回读 `...:FILT:DIG?`；确认 OFF 后才写量程和 NPLC。请求开启时，写 NPLC 后再发送 `SENS:<function>:FILT:DIG ON`，并再次检查错误队列和回读确认。采集中调速也按先 OFF/检查/回读、再写 NPLC、最后按请求 ON/检查/回读执行。已核实 OutG SW <2.0 时拒绝开启；版本未知时尝试命令并以错误队列和回读确认，未确认则配置失败。已核实版本低于 2.0 且请求关闭时，跳过滤波命令并继续配置 NPLC。平均读数数量随 DC 功能和量程变化，手册未给最大 `READ?` 响应时间；软件只有有限的主机端超时保护，不保证仪器时限。超时保存空值失败记录、停止采集并关闭串口，不伪造读数。依据《Programmers Manual Rev. 3》Table 13（PDF pp. 42–43 / printed pp. 32–33）、数字滤波命令（PDF pp. 58–60 / printed pp. 48–50）、CONF 预设 Table 18（PDF p. 51 / printed p. 41）、READ?（PDF p. 52 / printed p. 42）；《Users Manual Rev. 3》OutG SW <2.0 限制（PDF p. 47 / printed p. 3-3），滤波适用速率及平均数量（PDF p. 75 / printed p. 4-5）。400 mA电流量程有独立固件门槛。自动零点写 `ZERO:AUTO ON|OFF`。每次数据以单点 `READ?` 触发，之后读取实际 `...:RANG?` 并立即完整解析响应。

程序没有配置电容、RTD温度、外部电源输出或电压/电流同步双通道功能。若 `*IDN?` 返回8846A、其它型号或格式异常，连接会被拒绝。测试/Mock不提供实际电表精度保证。

**电流插孔边界：**官方用户手册将mA/400 mA和10 A画为两个独立前面板插孔，并要求按预期电流选择相应输入。编程手册的`ROUT:TERM?`只返回`FRON`或`REAR`；本程序另回读测量量程，但没有可据以确认红表笔实际插孔的状态。因此界面依选定量程提示mA/10 A接线，最终插孔和仪器面板输入选择仍须由操作者核对。这是对两个官方资料中端子图和SCPI查询范围的保守处理。

### ZERO与量程回读

`ZERO:AUTO ONCE`启动一次内部零点测量，`ZERO:AUTO?`只回读自动零点模式开关，并不返回零点测量值。软件执行ZERO后显示命令反馈和参数配置回读；配置回读不能证明零点测量值。自动量程下的`SENS:<function>:RANG?`作为独立档位快照显示，不覆盖“自动量程”配置，且可能随输入变化。依据《Programmers Manual Rev. 3》PDF第60页（印刷第50页）；使用模拟滤波时 ZERO 需匹配量程、NPLC和触发条件，见《Users Manual Rev. 3》附录D-1（PDF第99页）。

## 重要保守处理

- 模式参数先按手册的离散枚举验证。仪器错误队列非零时配置失败并中止，不继续保存看似有效的读数。
- `CONF` 后、单点 `READ?` 前只读验证触发源为 `IMM`、触发数和样本数均为1。手册将这些值列为 `CONF` 预设；若仪表回读不符，软件清除缓存测量模式并拒绝继续配置/采集，不另发触发写命令。`READ?` 会等待触发条件，BUS与EXT可能等待外部事件；本软件只支持单点立即触发采集。
- `LOCAL`面板控制时软件不发送配置、诊断、ZERO或采集命令；采集停止后可切回`COMPUTER`，并从仪表重新读取面板操作后当前的模式和参数。
- 400 mA 的 DCI 门槛明确对应 OutG SW ≥ 2.0（用户手册 Rev.3 PDF p.47 / printed p.3-3）。ACI 扩展规格列出软件版本 ≥ 1.0.700.18，但没有注明对应 OutG SW 还是 InG SW（PDF p.8 / printed p.7）；软件保留该要求作为界面提示，要求操作者核对仪表面板，不根据 OutG SW 或 InG SW 自动拒绝 ACI 400 mA 固定档或自动量程。`*IDN?`第四字段可能是用户自定义内容，即使可解析为点分数字也不用于量程判断。只使用按序列号保存的人工核对 OutG SW 执行 DCI 400 mA 门槛；InG SW 和 IDN 数字候选只作元数据记录。只有该 OutG SW 可解析且明确低于 2.0 时，才禁用 DCI 固定 400 mA 档和可能进入该档的自动量程。其它固定档不受此固件门槛影响。`SYST:VERS?` 返回 SCPI 命令版本，不是仪器软件版本。
- 固定1/3/10 A档仅在前面板端子显示可用：DCI的1 A标注为前面板专用，3 A属于10 A量程，且用户手册说明后面板不能测量10 A；ACI则直接将1/3/10 A标注为前面板专用。后端子下这些固定档被禁用，可能进入这些档位的电流自动量程也被阻止。400 mA的固件门槛与此端子限制分开判断。
- 原有`timestamp_local`/`timestamp_utc`保留主机`READ?`请求开始时间；`host_read_request_start_*`与`host_read_response_end_*`另存请求开始和收到响应/抛错边界的主机墙钟、单调时钟。响应结束在`READ?`查询获得结果或抛出错误时记录，不包括后续量程回读；`read_duration_s`也只覆盖该请求/响应窗口。`actual_interval_s`与桌面/Web遥测均按相邻有效响应结束单调时钟计算，异常行间隔留空。仪器没有逐样本硬件时间戳。并未使用资料中有额外条件的典型高速度作为保证。
- 用户设置的串口响应超时是普通SCPI命令的下限。对于 DC 数字滤波，官方用户手册说明平均读数数量随功能和量程变化，编程手册未给最大 `READ?` 响应时间；本软件的 `READ?` 超时是有限的主机等待值，并不保证仪器响应时限。响应超时会保存一条空值失败记录、停止采集并关闭串口，避免后续请求误读迟到数据。依据《Users Manual Rev. 3》PDF p. 75（printed p. 4-5）及《Programmers Manual Rev. 3》PDF p. 52（printed p. 42）。

### Commands sent by the application

After opening the serial port, connection sends `SYST:REM` before querying `*IDN?`, as required by the manual, then checks the instrument error queue after validating 8845A identity. If identification fails after REMOTE was attempted, the application makes a best-effort `SYST:LOC` before closing the port. When acquisition is stopped, the instrument settings panel can switch `SYST:LOC` (Local/front-panel control) and `SYST:REM` (Computer/remote control); switching back to Computer re-reads the active function and settings. A repeated Computer request re-sends `SYST:REM` and refreshes the instrument state even if the UI cache already says Computer. While a real connection is idle or paused in Computer mode, the worker queries `*IDN?` every 10 seconds to confirm the connection and 8845A identity. It skips probes during active continuous acquisition and in LOCAL or MOCK mode. A probe timeout, identity change, or serial error closes the connection and updates status; a paused experiment is finalized as failed. Normal disconnect sends `SYST:LOC`. The meter's RS-232 COMPUTER protocol selection is separate from this Local/Computer control state and must be set on the instrument. Function setup uses `CONF:VOLT:DC`, `CONF:VOLT:AC`, `CONF:CURR:DC`, `CONF:CURR:AC`, `CONF:RES`, or `CONF:FRES`. Autorange uses `SENS:<function>:RANG:AUTO ON`; fixed range uses `...:RANG:AUTO OFF` followed by `...:RANG <SI>`. Only DCV, DCI, RES, and FRES use `...:NPLC`. ACV/ACI set `SENS:DET:BAND <3|20|200>`. DCV explicitly sets and reads back `INP:IMP:AUTO`; ON uses >10 GΩ only at 100 mV, 1 V and 10 V ranges, while OFF is 10 MΩ at every range. Digital filtering is supported for DCV, DCI, 2-wire resistance, and 4-wire resistance, and the application permits enabling it only at NPLC 10 or 100 (rates slower than 1 PLC). `CONF` presets the filter ON, so configuration sends `SENS:<function>:FILT:DIG OFF`, checks the error queue, and verifies `...:FILT:DIG?` is OFF before writing range/NPLC. When ON is requested, it writes NPLC first, then sends `SENS:<function>:FILT:DIG ON`, checks the error queue, and verifies the ON readback. Live speed changes use the same OFF/check/readback, NPLC, and requested ON/check/readback sequence. A panel-verified OutG SW below 2.0 rejects an ON request; an unknown version is probed and must pass the error-queue and readback checks. When a verified older version is configured with filtering OFF, the unsupported filter command is skipped and NPLC can still be set. The manuals say the number of averaged readings varies by DC function and range and do not specify a maximum `READ?` response time. The application therefore uses only a finite host-side timeout; it does not guarantee a meter response deadline. On timeout it stores a blank failed attempt, stops acquisition, and closes the serial connection. Auto-zero uses `ZERO:AUTO ON|OFF`. Each point uses `READ?`, followed by a query of the actual range and complete response parsing.

The application does not configure capacitance, RTD temperature, source output, or synchronous dual voltage/current channels. A response identifying an 8846A, another model, or malformed identity is rejected. Tests and Mock mode do not establish real-meter accuracy.

### Conservative implementation boundaries

- Parameters are validated against documented discrete values. A non-zero instrument error queue aborts configuration and acquisition.
- After `CONF` and before one-point `READ?`, the application reads `TRIG:SOUR?`, `TRIG:COUN?` and `SAMP:COUN?` and requires `IMM`, 1 and 1. The manual lists these as `CONF` presets. A mismatch clears the cached mode and aborts further configuration/acquisition without sending separate trigger-setting commands; the application supports one-point immediate-trigger acquisition only.
- In `LOCAL` panel-control mode, the application sends no configuration, diagnostic, ZERO, or acquisition commands. After panel operation, switching back to `COMPUTER` re-reads the current function and settings.
- The fixed 400 mA DCI threshold explicitly maps to OutG SW ≥ 2.0. The ACI specification lists software version ≥ 1.0.700.18 but does not identify OutG versus InG; the application presents this as a panel-check requirement and does not automatically reject the ACI 400 mA fixed range or autorange based on either field. Only DCI 400 mA fixed range and DCI autorange are blocked when manually recorded OutG SW is parseable and explicitly below 2.0. The `*IDN?` revision field may be user-defined, so even a parseable number is not used as firmware evidence. InG SW and numeric IDN candidates are metadata only. Unknown or unparseable OutG SW does not block DCI; other fixed ranges are unaffected by this firmware gate. `SYST:VERS?` returns the SCPI command version, not instrument software. Manual panel entries are distinguished from SCPI data in experiment metadata.
- Fixed 1/3/10 A ranges are exposed only when front-panel terminals are confirmed: DCI marks 1 A front-only, 3 A is part of the 10 A range, and the user manual says rear terminals cannot measure 10 A; ACI marks 1/3/10 A front-only. Rear operation blocks those fixed ranges and current autorange that may enter them. The 400 mA firmware threshold is checked independently.
- Existing `timestamp_local`/`timestamp_utc` retain the host `READ?` request-start time. `host_read_request_start_*` and `host_read_response_end_*` additionally store the host wall-clock and monotonic request/response boundaries. The response end is captured when the `READ?` query returns a response or raises, before any later range query; `read_duration_s` covers only this request/response window. `actual_interval_s` and desktop/Web telemetry use the difference between consecutive valid response-end monotonic timestamps; invalid rows have no interval. The meter supplies no hardware timestamp per sample. Published typical maximum speeds are not treated as guarantees.
- The configured serial timeout is the floor for ordinary SCPI commands. The host provides a finite `READ?` timeout, but the supplied manuals do not specify a maximum digital-filter response time; the stated average count varies by DC function and range. This timeout is host-side protection, not a Fluke timing guarantee. On timeout the application saves a blank failed attempt, stops acquisition, and closes the serial session before another query can consume a delayed response. See the *Users Manual*, Rev. 3, PDF p. 75 (printed p. 4-5), and *Programmers Manual*, Rev. 3, PDF p. 52 (printed p. 42).
- DCV automatic input impedance defaults OFF (10 MΩ); ON selects >10 GΩ only for 100 mV, 1 V and 10 V ranges. The application writes and verifies this setting only for DCV.
- Digital filtering applies to DCV/DCI/RES/FRES and is enabled in the application only at NPLC 10 or 100. `CONF` presets it ON; the application sends OFF and verifies the error queue/readback before range/NPLC, then sends ON and verifies again only when requested. Known OutG SW below 2.0 rejects ON; unknown versions are probed and validated. The number of averaged readings varies with function/range, and the supplied manuals specify no maximum `READ?` response time. The application has a finite host timeout; timeout is recorded as a failed attempt and stops acquisition, without a meter timing guarantee. See the *Programmers Manual*, Rev. 3, Table 13, PDF pp. 42–43 (printed pp. 32–33), filter commands pp. 58–60 (printed pp. 48–50), `CONF` preset Table 18 p. 51 (printed p. 41), `READ?` p. 52 (printed p. 42), and the *Users Manual*, Rev. 3, PDF pp. 47 and 75 (printed pp. 3-3 and 4-5).
- The manual shows separate mA/400 mA and 10 A jacks. `ROUT:TERM?` reports only FRONT/REAR, and range readback cannot identify the physical red jack. The operator must verify the lead and front-panel input selection.
