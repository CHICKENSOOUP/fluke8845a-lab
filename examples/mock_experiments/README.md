# Mock 实验示例 | Mock Experiment Examples

[简体中文](#简体中文) | [English](#english)

## 简体中文

本目录下六种模式的 CSV、JSON、事件和日志全部由内置 MOCK 后端生成。它们只用于演示导入、曲线、统计和文件格式，不代表真实 Fluke 8845A 测量结果。

可用以下命令重新生成到一个新的目标目录；生成器会拒绝覆盖已存在的目录：

```powershell
python scripts/generate_demo.py --output dist/mock_experiments_regenerated
```

## English

All six-mode CSV, JSON, event, and log examples in this directory were generated by the built-in Mock backend. They demonstrate import, plotting, statistics, and file formats only; they are not measurements from a physical Fluke 8845A.

Regenerate the examples into a new destination with `python scripts/generate_demo.py --output dist/mock_experiments_regenerated`. The generator refuses to overwrite an existing destination.
